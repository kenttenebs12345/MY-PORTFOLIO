# Kent Michael G. Tenebro — Portfolio

A static HTML and CSS portfolio. The site entry point is `index.html`; its pages and images are stored alongside it.

## Publish with GitHub Pages

1. Create a GitHub repository and upload the contents of this folder, keeping `index.html`, `style.css`, the other HTML pages, and the `img` folder together at the repository root.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select the branch containing the site (usually `main`) and the `/(root)` folder, then save.
4. Open the published URL shown on the Pages settings screen.

The site uses relative links and does not require a build step or external packages.
